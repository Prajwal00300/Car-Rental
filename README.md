# Car Rental Web Application

A full-stack car rental web application built using the MERN stack. The platform allows users to browse available cars, view car details, and make rental bookings. An admin panel is included for managing cars and bookings.

## Features

- User registration and login
- JWT-based authentication
- Browse available rental cars
- View detailed car information
- Car booking functionality
- Booking management
- Admin dashboard
- Add, update, and delete cars
- Image upload and management using ImageKit
- RESTful APIs
- Responsive user interface

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- React Router
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- REST APIs

### Other Tools
- ImageKit for image storage and management
- Git & GitHub

## Project Architecture

The application follows a client-server architecture:

React.js Frontend → REST APIs → Node.js/Express Backend → MongoDB

Authentication is handled using JWT, while ImageKit is used to manage car images.

## Purpose

This project was built to gain practical experience in developing and deploying a complete MERN stack application, including authentication, CRUD operations, API development, database integration, image management, and booking workflows.
